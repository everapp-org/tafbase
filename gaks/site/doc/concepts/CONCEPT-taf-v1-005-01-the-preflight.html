Definition#

A declared gate before a run — requires: in the model (mail-server up, appium listening) — checked once, failing the whole suite fast and saying why. Its runtime form is the circuit breaker: the old framework's suiteStopReason flag that, once set (the mail server died), failed every subsequent test immediately rather than logging 40 identical red herrings.

Why it exists#

Forty tests all failing "connection refused" is noise that costs an hour of triage before anyone asks whether the server was even up. Refusing early — with a named reason — is the same honesty the model loader applies statically, applied to a run's prerequisites. A suite that knows its requirements stops spending test failures on infrastructure facts.

In this project#

Partly landed — lane L-12. The static analogue exists: taf check's refusals list every reason instead of dying on the first. The report form exists: taf dry-run names what a run lacks (CONCEPT-taf-v1-008-01-the-dry-run). The gate form begins: taf run probes by default and refuses to start while a probe finding is missing — before a browser opens. --no-probe skips the gate entirely: probes never run, env needs warn instead of refusing. Still planned: requires: — the declared gate, the run-time version of the same contract.
