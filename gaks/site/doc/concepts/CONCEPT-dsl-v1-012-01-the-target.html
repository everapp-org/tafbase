Definition#

device: and env: header clauses — Pixel9ProXL_chrome, qa, uat — resolved at emit time into the capabilities block and base URL the suite launches with. One token, everything derived.

Why it exists#

The old framework parsed a resolution string at runtime — w10_chrome, GalaxyS25Ultra_samsung, iPhone16Pro_safari — through ~300 lines of factory dispatching on OS, browser, device, local CDP emulation or BrowserStack. It was already a mini-DSL with a runtime interpreter. Generated code does better: the vocabulary is validated at emit time, the emitted suite carries the exact capabilities object, and the tag-to-environment mapping (@qa_env -> suite + URL + locator version) bakes in the same way. The layered property files it replaced — root defaults, module config, user overrides — become inputs to codegen, resolved once and printed into the suite header.
